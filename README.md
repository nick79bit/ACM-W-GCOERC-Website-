ACM-W GCOERC Website

A responsive and user-friendly website developed for the Association for Computing Machinery – Women (ACM-W), GCOERC, to showcase the community's initiatives, events, activities, and commitment to empowering women in computing. The website provides an engaging digital presence for the student chapter, highlighting opportunities for technical learning, collaboration, mentorship, and women’s participation in technology.
